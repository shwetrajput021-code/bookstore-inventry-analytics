📚 Bookstore Data Analysis System

Turning Bookstore Data into Meaningful Insights

A Python-based data analytics project designed to analyze bookstore inventory, track sales performance, calculate revenue, and identify best-selling books using real-world data analysis techniques.

---

🚀 Project Highlights

- 📦 Inventory Management — View books, prices, authors, and available stock.
- 💰 Revenue Analysis — Calculate total sales revenue.
- 📈 Sales Performance — Identify the best-selling book.
- 📊 Stock Analysis — Calculate total inventory and available quantities.
- 📁 CSV Data Management — Store and read inventory and sales records.
- 🐍 Python Programming — Apply functions, conditions, and basic OOP concepts.

---

🛠️ Tech Stack

NumPy| Numerical calculations
